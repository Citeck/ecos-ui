# Lexical: пункты меню ячейки таблицы выровнены по центру (COREDEV-455)

## Проблема

В контекстном меню ячейки таблицы (шеврон в ячейке → `TableActionMenu`) часть пунктов стояла по
центру, часть — по левому краю. Тестировщик перечислил «Объединить ячейки», «Цвет фона»,
«Переключить чередование строк», «Вертикальное выравнивание», «Закрепить/открепить первую
строку/столбец».

Замер на локальном стенде (русский интерфейс, отступ строк подписи от левого края `.text`):

| пункт | до | после |
|---|---|---|
| «Переключить чередование строк» (2 строки) | 16 / 97 px | 0 / 0 |
| «Закрепить/открепить первую строку» (2 строки) | 8 / 93 px | 0 / 0 |
| «Закрепить/открепить первый столбец» (2 строки) | 7 / 88 px | 0 / 0 |
| однострочные («Цвет фона», «Удалить строку», …) | 0 | 0 |

То есть по центру стояли ровно те подписи, которые **переносятся на вторую строку** — самые длинные
русские; однострочные всегда были слева. На английском интерфейсе ни одна подпись не переносится,
и бага не видно.

## Корневая причина

Пункт меню — `<button class="item">` (`plugins/TableActionMenuPlugin/TableActionMenu.tsx`). У кнопки
браузерный default `text-align: center`, а в `Lexical/index.scss` блок
`.citeck-lexical-editor__dropdown .dropdown .item` его не сбрасывал. Подпись `.item .text` —
`display: flex; flex-grow: 1; min-width: 180px`: однострочный текст в ней — анонимный flex-элемент
шириной по содержимому, прижат к началу и центрирования не показывает; текст с переносом занимает
всю ширину `.text`, и строки внутри него центрируются унаследованным `text-align`. Локальная
заплатка от того же бага уже была у подменю вертикального выравнивания
(`.item.wide .icon-text-container .text { text-align: left }`).

## Исправление

`src/components/editors/Lexical/index.scss`: `text-align: left` у `.dropdown .item` и у дубля
`&__dropdown .item`. Меню тулбара (`item.wide` с шорткатом справа) не затронуто — там подпись и
шорткат расставлены flex'ом.

## Проверка

Браузер (локальный стенд, `/v2/dashboard?ws=TEST&recordRef=emodel/ept-issue@TEST-1`, комментарий →
«Вставка» → «Таблица» → шеврон ячейки; язык «Рус» через меню пользователя): у всех 14 пунктов
`text-align: left`, все строки подписей с отступом 0 (`Range.getClientRects()` относительно
`.text`); меню тулбара «Обычный/Заголовок…» — подпись слева, шорткат справа, как и было.
