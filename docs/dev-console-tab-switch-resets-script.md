# Консоль разработчика: переключение вкладок сбрасывало скрипт и историю (COREDEV-3691)

## Проблема

Открыть консоль разработчика → выбрать пример → поправить его (вручную или ИИ-ассистентом) →
переключиться на другую вкладку citeck и вернуться. В редакторе снова текст примера, правки
пропали, кнопки «отменить»/«повторить» заблокированы. При этом после закрытия и повторного
открытия вкладки консоли показывался скрипт **с правками** — в `localStorage` он сохранялся.

## Корневая причина

`AdminPage` берёт `urlParams` из `window.location` (`getSearchParams()`), а `AdminSection.isHidden`
сравнивает `urlParams.type` с типом секции. `window.location` всегда описывает **активную**
вкладку, поэтому при переходе на любую другую вкладку у всех админ-секций `hidden` становится
`true`, хотя сама вкладка остаётся смонтированной (панель неактивной вкладки прячется через
`display: none`).

Все секции (`DevTools`, `BPMNDesigner`, `BpmAdministration`, `JournalViewer`) на `hidden`
отвечают классом `d-none`. `DeveloperConsole` — единственная делала `return null`. Это
размонтировало `CodeEditor`, Monaco уничтожал модель вместе со стеком undo/redo; при возврате
редактор монтировался заново с `defaultValue={initialValue}` — а `initialValue` обновляется только
при выборе примера/сниппета, не при вводе. Отсюда «откат к шагу 2» и заблокированные кнопки.

## Исправление

`src/pages/DeveloperConsole/DeveloperConsole.tsx`:

- Скрытие через `d-none` на корневом контейнере, как у остальных секций. Monaco с
  `automaticLayout: true` сам перекладывается после снятия `display: none`.
- Ленивый монтаж: состояние `wasShown` поднимается при первом `hidden === false`, до этого
  компонент возвращает `null`. Так Monaco по-прежнему не грузится у админов, которые консоль не
  открывали, а после первого показа редактор больше не размонтируется.

Тест: `src/pages/DeveloperConsole/__tests__/DeveloperConsole.test.js` — редактор переживает цикл
hidden → shown как тот же DOM-узел с единственным монтированием; в скрытом состоянии корень
несёт `d-none`; до первого показа редактор не монтируется.

## Проверка в браузере

Локальный стенд: `/v2/admin?type=DEV_CONSOLE&ws=user$admin` (тип секции — в верхнем регистре;
`type=dev-console` не выбирает ни одну секцию, страница пустая). Сценарий: пример → дописать
строку → открыть вкладку дашборда кликом по ссылке → вернуться. Текст с правкой на месте, модель
Monaco одна и та же, «отменить» активна и откатывает ввод, «повторить» становится активной.
